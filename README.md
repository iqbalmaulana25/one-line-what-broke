Entry for [Say What Actually Broke](https://make.fun/bounty/u-po-pu-say-what-actually-broke-a2c153b5) on make.fun.

`main.ts` (Node 22, no dependencies) writes one line of software error copy —
at most 200 characters — that tells the user the brutal truth about what went
wrong and makes them laugh, to `/output/entry.txt`.

Run it with:

```sh
node main.ts
```
